# Olala Viajes

Sitio web para agencia de viajes con catálogo de paquetes turísticos y sistema de reservas. Desarrollado para Olala Viajes, Argentina.

## 📋 Funcionalidades

- Catálogo de paquetes turísticos con fotos, descripción e itinerario
- Sistema de reservas online
- Panel de administración para gestión de paquetes
- Formulario de contacto

## 🛠️ Tecnologías

- Python
- Django
- SQLite
- HTML5, CSS3, JavaScript
